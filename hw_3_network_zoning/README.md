# Домашнее задание №3: Концепция сетевого зонирования облачных приложений (3-Tier Architecture)

## 1. Цель работы
Построить трёхзвенную сетевую инфраструктуру в **Yandex Cloud** с изоляцией слоёв на уровне подсетей, таблиц маршрутизации, NAT Gateway и групп безопасности (`Security Groups`).

## 2. Архитектура решения (`main.tf`)
* **`subnet-frontend-public` (`10.10.1.0/24`):** публичная подсеть, ВМ `vm-frontend` (`10.10.1.10`, порт `80`) с внешним IP. Группа безопасности `sg-frontend` разрешает входящий трафик `0.0.0.0/0` на порт `80`.
* **`subnet-backend-private` (`10.10.2.0/24`):** приватная подсеть без публичного IP, привязана к таблице маршрутизации на **NAT Gateway** (`yandex_vpc_gateway`) для скачивания обновлений. ВМ `vm-backend` (`10.10.2.10`, порт `3000`). Группа безопасности `sg-backend` принимает трафик на порт `3000` **только** из подсети Frontend (`10.10.1.0/24`).
* **`subnet-db-private` (`10.10.3.0/24`):** изолированная приватная подсеть без публичного IP и без выхода в интернет. ВМ `vm-db` (`10.10.3.10`, порт `6000`). Группа безопасности `sg-db` принимает трафик на порт `6000` **только** из подсети Backend (`10.10.2.0/24`).

## 3. Результаты тестирования трафика
1. `Internet -> Frontend (80)`: **Tier 1: FRONTEND (Port 80) OK**
2. `Frontend (10.10.1.10) -> Backend (10.10.2.10:3000)`: **Tier 2: BACKEND (Port 3000) OK**
3. `Frontend (10.10.1.10) -> DB (10.10.3.10:6000)`: **Connection timed out (Заблокировано группой безопасности `sg-db`)**
4. `Backend (10.10.2.10) -> DB (10.10.3.10:6000)` и `Backend -> Internet (NAT GW)`: **Tier 3: DATABASE (Port 6000) OK** и **HTTP/2 200**
