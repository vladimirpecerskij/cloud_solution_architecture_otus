# Cloud Solution Architecture (OTUS)

Репозиторий с практическими работами по курсу проектирования облачных архитектур в **Yandex Cloud**.

## Содержание
* **[`hw_1_iam/`](./hw_1_iam)** — Разграничение прав доступа (IAM) к ресурсам Object Storage в зависимости от категории пользователя с помощью **Terraform** и **YC CLI**.
* **[`hw_2_vpc_routing/`](./hw_2_vpc_routing)** — Проектирование сетевой топологии из 3 изолированных **VPC**, таблиц маршрутизации (`Route Tables`) и ВМ-маршрутизатора с фильтрацией трафика.
* **[`hw_3_network_zoning/`](./hw_3_network_zoning)** — Трёхзвенное сетевое зонирование (**Frontend / Backend / DB**), микросегментация через **Security Groups** и выход приватного слоя в интернет через **NAT Gateway**.
